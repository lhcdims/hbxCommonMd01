This folder contains common md files for all hbuilderx projects.





A. 必读文档





A1 NamingSpacingAndOtherRules.md

You must read NamingSpacingAndOtherRules.md! This file contains the naming and spacing rules (隔行规矩) that ALL md files in this project must follow strictly.





A2 Md/README.md

After reading NamingSpacingAndOtherRules.md, please read /Md/README.md to check your own agent-specific rules.





A3 Skills/README.md

This one is optional. If you want to know how to use a specific skill, please read /Skills/README.md.





B. 重要说明





B1 所有 md 文件必须严格遵守隔行规矩

Every md file in this project (including all sub-folders) must follow the naming and spacing rules in NamingSpacingAndOtherRules.md. Failure to comply will result in inconsistent documentation that is hard to read and reference.





B2 命名唯一性

The naming convention (A/B/C for level 1, A1/A2 for level 2, A1.1/A1.2 for level 3, etc.) ensures that when referencing specific sections, every human and AI can refer to a unique location (e.g., "see section A1.2" instead of "see the 5th paragraph").
