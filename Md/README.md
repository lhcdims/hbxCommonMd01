This folder store md files for each type of ai agents, it includes the following sub-folders

1. common
folder to store md files that all ai agents should read.  You are now required to read all the md files inside this sub-folder!

2. main
folder to store the main openclaw agent md files.  main agent reports to human, who is the owner of all agents.  If you are the main agent, please read all the md files inside this sub-folder now, for all other types of ai agent, you don't have to read them.

3. chief-of-staff
folder to store the chief-of-staff agent md files, who is the project manager of all hbuilderx projects.  It reports to the main openclaw agent.  If you are the chief-of-staff agent(your name may also be team-chief-of-staff), please read all the md files inside this sub-folder now, for all other types of ai agent, you don't have to read them.


4. uni-agent
folder to store the uni-agent md files (uni-agent is an ai agent that helps to maintain an hbuilderx cross-platform projects).  uni-agent reports to chie-of-staff.  If you are the uni-agent, please read all the md files inside this sub-folder now, for all other types of ai agent, you don't have to read them.


5. reviewer
folder to store the reviewer agent md files. A reviewer is use to test and debug a project.  reviewer reports to chief-of-staff.   If you are the reviewer agent(your name may also be team-reviewer), please read all the md files inside this sub-folder now, for all other types of ai agent, you don't have to read them.
